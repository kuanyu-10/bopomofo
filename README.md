# 注音符号表｜日本語学習者向け

日本人の初心者に向けて、台湾華語で使う37個の注音符号を学習するシンプルなサイトです。

## 使い方

1. `index.html` を Chrome で開きます。
2. ホームに37文字の注音符号表を表示します。
3. 左側の注音符号をクリックすると、教育部のWAVファイルが再生されます。
4. 右側の例単語には **漢字・注音（声調付き）・日本語の近似音・日本語の意味** を表示します。クリックするとブラウザが台湾華語で例単語を読み上げます。
5. 一覧の下にある「声調の練習」で四声と軽声を聞き比べます。
6. 右上の「クイズ」をクリックすると10問4択のテストに挑戦できます（声調はクイズの対象外）。

**重要：** カタカナで表した発音は日本語での「目安」であり、実際の中国語の子音・母音・声調を忠実に表すものではありません。実際の発音は音声を優先してください。中国語の読み上げ（SpeechSynthesis）はブラウザとOSの中国語音声対応状況によって動作が変わります。

## ファイル構成

- `index.html`：ページ構造、ヘッダー（ホーム／クイズ）、フッター
- `style.css`：白地と黒字だけを使った画面デザイン
- `data.js`：37個の注音・日本語の近似音・例単語・注音表記・五声調の例
- `script.js`：画面切り替え、注音WAV、例単語と声調の読み上げ、クイズ
- `audio/F1.WAV` ～ `audio/F37.WAV`：教育部発音音声
- `license.txt`：音声素材の原文ライセンス

## コメントの構成と学習の進め方

`index.html` / `style.css` / `data.js` / `script.js` の `STEP` コメントに沿って、少しずつ読んで動作を確認できます。授業では AI が作ったものをそのまま提出することは避け、自分で理解して書き直した変更と確認結果を Git の履歴に残してください。

## 声調の表示

第一声：記号なし、第二声：ˊ、第三声：ˇ、第四声：ˋ、軽声：˙（このサイトでは例：`˙ㄗ` のように先頭に表記）

## 声調の追加実装について

- 第1声から第4声までと軽声のカードを追加しました。「八・拔・把・爸・吧」を使い、軽声の「吧」も一文字だけ読み上げます。単独の合成音声では軽声が正確に再現されない場合があります。
- 発音は音源ファイルではなく、ブラウザの `SpeechSynthesis` を使用します。中国語音声の声調の自然さは OS・ブラウザ・音声ごとに異なります。
- 単語の音声が期待どおりでない場合は、実際の台湾華語話者の録音による確認が必要です。
- `index.html` の STEP 07、`data.js` の STEP 03、`script.js` の STEP 08 に関連コードを分けています。
